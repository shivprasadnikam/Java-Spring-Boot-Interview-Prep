# Java Backend Interview Q&A (Spring Boot) — 15–20 LPA

## Who this repo is for
- Java/Spring Boot backend engineers with 3–5 years of experience.
- Candidates preparing for product-company interviews at 15–20 LPA.
- Engineers who want concise, production-grade answers (not textbook theory).

## Topics covered
- Core Java: OOPs, Collections, Multithreading, Java 8+.
- Spring Core: Dependency Injection, Bean Lifecycle, Annotations.
- Spring Boot: Boot basics, Auto-configuration, Profiles/Properties.
- REST APIs: REST basics, HTTP status codes, exception handling.
- Spring Data JPA: Entity lifecycle, mappings, queries, transactions, performance.
- Security: Spring Security, JWT.
- Microservices: Basics, service discovery, API gateway, communication.
- Kafka: Core concepts and interview traps.
- Cloud (AWS): Core services, deployment, load balancing.
- DevOps: Docker, Kubernetes, CI/CD.
- System Design: Fundamentals + common backend systems.

## How to use this repo for interview prep
- Read a topic end-to-end, then re-answer each question out loud.
- Focus on trade-offs: when to use, when to avoid, and common pitfalls.
- Add your project context to the examples (interviewers expect real-world grounding).
- Revisit weak areas weekly; dont just read once and move on.

## Suggested 30-day revision plan
- Days 1–7: Core Java + Spring Core (fundamentals + DI).
- Days 8–14: Spring Boot + REST API basics.
- Days 15–21: Spring Data JPA (mappings, transactions, performance).
- Days 22–26: Security + Microservices + Kafka.
- Days 27–30: AWS + DevOps + System Design drills.

## Author note
This is written in the tone of real interview panels. Expect follow-ups on pitfalls,
trade-offs, and production failures. Keep answers concise but opinionated.
